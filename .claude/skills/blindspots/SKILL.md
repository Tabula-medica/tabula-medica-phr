# /blindspots

Subject: $ARGUMENTS

Read `CLAUDE.md` for the project's domain and rules, then list:

1. **Unstated assumptions** the subject depends on, each with what happens if it is false.
2. **Missing constraints**: time, money, people, data, legal, platform.
3. **Second-order effects**: what this changes for users, ops, cost, and other systems after it ships.
4. **Regulatory and compliance angles** when the project has them.
5. **The question you should have asked instead**, if there is one.

Bullets only. No restating the plan. Rank each list by how much it would change the decision.
