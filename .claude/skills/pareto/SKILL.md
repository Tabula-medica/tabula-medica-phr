# /pareto

Input: $ARGUMENTS

1. State the goal in one line and the metric that defines success.
2. List every candidate action. Score each: impact on the metric (1–5) and effort (1–5).
3. Rank by impact divided by effort. Show the table.
4. **Do these**: the top items that together cover most of the impact.
5. **Drop or defer**: everything else, with a one-line reason each.
6. Name the first action to take today.
