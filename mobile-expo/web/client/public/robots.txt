# Tabula Medica — robots.txt
#
# One consolidated `User-agent: *` group governs ALL crawlers — search engines
# (Googlebot, Bingbot, etc.) AND AI/LLM crawlers (GPTBot, ClaudeBot,
# PerplexityBot, etc.). We do this on purpose: per the robots.txt spec a bot
# obeys only the single most-specific matching group, so giving each bot its
# own `Allow: /`-only group would silently drop the Disallow rules below for
# exactly the crawlers that matter most. Keeping a single group means the
# private-route protections apply to everyone.
#
# Public marketing pages and patient-facing content are open to all crawlers,
# including AI training/answer crawlers (AEO/GEO), so the brand and product
# information can surface in AI Overviews, ChatGPT, Claude, Perplexity, etc.
# We intentionally do NOT block AI crawlers from public content.
#
# Authenticated routes are protected by auth at the application layer (no PHI
# ever renders without a valid session); we still disallow crawling them so
# empty app shells don't get indexed.

# --- The noindex-vs-Disallow split (READ BEFORE ADDING A ROUTE) ---
# Every route falls into exactly ONE of three buckets:
#   1. INDEXABLE — public marketing/tool pages. Listed in sitemap.xml AND in
#      INDEXABLE_ROUTES in web/client/src/App.tsx. Served `index, follow`.
#      NEVER Disallow these.
#   2. noindex (must stay CRAWLABLE) — any route NOT in INDEXABLE_ROUTES gets a
#      JS-injected `noindex, nofollow` (see App.tsx). This is the default and it
#      relies on the crawler EXECUTING the page to read the tag, so the route
#      must NOT be Disallowed here — a Disallowed route is never fetched, so the
#      noindex tag is never seen. Use this bucket for borderline informational /
#      compliance / marketing pages we want kept out of the index but still
#      reachable (e.g. /welcome, /trust-center, /gdpr, /ccpa, /accessibility).
#   3. Disallow (URL-only suppression) — genuinely private, auth-gated PHI /
#      account app shells below. They carry no public value and never need to be
#      crawled, so we hard-block them here. This stops non-JS crawlers (which
#      never see the bucket-2 noindex tag) from listing the bare URL. Because
#      these are blocked from crawling, do NOT also depend on noindex for them —
#      Disallow alone is the suppression mechanism.
# RULE: a route is EITHER bucket 2 (crawlable + noindex) OR bucket 3 (Disallow),
# never both. Never put an INDEXABLE_ROUTES path in bucket 3.
